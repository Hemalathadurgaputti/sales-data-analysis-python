# Sales Data Analysis Using Python

## Project Overview
This project analyzes sales data using Python to identify product performance, monthly sales trends, country-wise sales, and customer contributions. The goal is to turn raw sales records into meaningful business insights using data analysis and visualization.

## Objectives
- Analyze overall sales performance.
- Identify the highest- and lowest-performing product lines.
- Explore monthly sales trends.
- Compare sales across countries and deal sizes.
- Identify top customers by total sales.
- Visualize patterns and relationships in the data.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset
The dataset contains 2,823 records and 25 columns, including order dates, sales amounts, product lines, customer names, countries, quantities ordered, and deal sizes.

## Data Preparation
- Inspected the dataset structure and data types.
- Checked for duplicate rows and missing values.
- Converted ORDERDATE into a datetime format.
- Examined numerical summaries and sales values.

## Analysis Performed
- Total sales by product line
- Monthly sales trends
- Country-wise sales
- Quantity ordered by product line
- Sales by deal size
- Top 10 customers by sales
- Correlation analysis of numerical variables
- Distribution of order sales
- Relationship between order quantity and sales
- Potential outlier analysis

## Key Findings
- **Total sales:** 10,032,628.85
- **Unique orders:** 307
- **Unique customers:** 92
- **Average sales per order:** 32,679.57
- **Top product line by total sales:** Classic Cars, with 3,919,615.66 in sales.
- **Lowest product line by total sales:** Trains, with 226,243.47 in sales.

## Visualizations

- Box plots

## Conclusion
This project demonstrates how Python can be used to inspect, analyze, and visualize sales data. The analysis identifies differences in product-line performance and explores trends across time, markets, and customers.
